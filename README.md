# 蛙蛙平台作者·签约一键填充（Chrome / Edge 插件）

> **适用范围**：开箱即用支持蛙蛙平台通过法大大（cloud.fadada.com）发起的《个人作品著作权转让协议》签署页；**其他法大大合同模板可通过"学习模式"自行添加**（见下文）。

自动填充签署页的填写控件。v1.1.0 起支持**多套资料**与**模板学习**。

## 内置模板：3 个控件的对应关系（2026-09 起的签署页）

| 控件（合同里的名字） | 含义 |
|----------------------|------|
| 地址 | 联系地址 |
| 邮箱 | 邮箱 |
| 填写日期2 | 填写日期，**默认自动填当天**（资料里留空即可；也可固定填指定日期） |

> 2026-09 平台改版后签署页只剩这 3 个待填控件；旧版 13 控件页面已不再出现。
> 书名字段由平台自动带出，不在待填列表里，无需配置。

## 安装（一次性）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点左上角「加载已解压的扩展程序」，选择本目录（`fadada-autofill`）
4. （推荐）在扩展列表里找到本插件 → 固定到工具栏

Edge 用户：`edge://extensions` → 开发者模式 → 加载解压缩的扩展，同样适用。

## 使用

1. 首次使用：打开一个已填过/待填的签署页 → 点插件图标 → 填好地址、邮箱两项（填写日期留空即自动填当天；也可点「读取当前值」从页面抓取）→ **保存**
2. 以后每次：从墨语平台打开新的签署页，插件会**自动填充**（只填空框，不覆盖已有内容；日期永远填当天），也可以：
   - 点页面右下角悬浮按钮「⚡ 填充」
   - 或点插件图标 →「立即填充本页」（覆盖式填充所有已配置项）
3. 核对无误后手动点页面上的「确认提交」——**插件不会替你提交**

## 多套资料

弹窗顶部「资料」区可**新建 / 复制 / 删除**多套资料（如：主号、小号、不同收款账户），下拉切换。签署时用哪套，自动填充就填哪套。

## 学习新合同模板

遇到内置模板没覆盖的法大大合同时：

1. 在该签署页上**手动填一遍**（内容随意，建议就用真实值，插件会自动猜）
2. 点插件图标 → 「当前页模板」区会显示"未识别的模板" → 点**「学习此模板」**
3. 每个控件选一个对应字段（插件按你手填的内容和格式自动预选：身份证/手机/邮箱/银行卡号能认出来；选「— 忽略 —」则跳过该框）→ 给模板起个名 → **保存模板**
4. 以后打开同模板的签署页，插件按控件名称序列做指纹匹配，自动套用

已学习的模板在弹窗里列出，可随时删除重新学。

**控件多了少了都不影响**：模板记录的是"控件位置 → 字段"的映射，控件比字段多就忽略多余的，比字段少就闲置不用的。如果新模板里有内置 3 项之外的字段类型（如 QQ 号、税号），在「自定义字段」区点「+ 添加字段」补一个，学习时就能选到它。

## 自定义字段

弹窗「自定义字段」区可添加任意字段（字段名 + 每套资料各自的值），与内置 3 项同等参与学习映射和填充。删除字段会连带清掉各资料里存的值。

## 说明与注意事项

- 数据只存在本机 `chrome.storage.local`，不上传任何服务器
- 模板指纹 = 「待处理控件」面板的控件名称序列；若平台改动模板导致识别变化，重新学习一次即可
- 「打开签署页自动填充」和「悬浮按钮」都可以在弹窗里开关
- 更新插件代码后，需要在 `chrome://extensions` 里点一下插件的刷新图标，再刷新已打开的签署页

## 目录结构

```
fadada-autofill/
├── manifest.json   # MV3 清单
├── content.js      # 页面注入脚本：识别控件、写入值（Vue/Element 兼容）
├── popup.html      # 弹窗界面
├── popup.js        # 弹窗逻辑：编辑资料、读写 storage、发填充指令
└── icon128.png     # 图标（商店上架必需）
```

## 发布到 Chrome 应用商店（可选）

本插件满足上架的基本条件：MV3、单一用途、无远程代码、数据只存本机（不上传）。名称已按「仅服务蛙蛙平台作者」定位，描述中明示了适用范围。

发布步骤：

1. 注册开发者账号：https://chrome.google.com/webstore/devconsole ，一次性 $5 注册费（需能访问谷歌及外币支付）
2. 打包 zip 已备好：桌面上的 `fadada-autofill-store.zip`（manifest.json 在 zip 根目录）
3. 上传新商品 → 填名称/描述/分类（可用「生产力工具」）→ 上传 1280×800 截图 1~5 张
4. 隐私声明：填「不收集用户数据」（值仅存 chrome.storage.local）
5. 提交审核，新插件一般 1~7 天通过

**截图注意**：商店截图里不要出现真实身份证号/手机号等个人信息——截图前先在弹窗里清空或填假数据（如"张三 / 110101...X"）。
