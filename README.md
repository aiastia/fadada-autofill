# 蛙蛙平台作者·签约一键填充（Chrome 插件）

> **适用范围**：仅适用于蛙蛙平台（124678.xyz）通过法大大（cloud.fadada.com）发起的《个人作品著作权转让协议》签署页。其他法大大合同模板的控件顺序不同，请勿使用。

自动填充签署页的 13 个填写控件。

## 13 个控件的对应关系

| 组 | 控件（合同里的名字） | 位置 | 含义 |
|----|----------------------|------|------|
| 个人信息 | 单行文本1 ×6 | 第 1 页 | 真实姓名 / 笔名 / 身份证号 / 联系地址 / 手机号 / 邮箱 |
| 收款账户 | 单行文本3 ×4 | 第 5 页 | 开户名称 / 开户行 / 开户支行 / 银行账号 |
| 授权书 | 单行文本4 / 5 / 6 | 第 10 页 | 姓名 / 身份证号 / 笔名（附件一《著作权独家授权证明》） |

> 书名字段由平台自动带出，不在待填列表里，无需配置。

## 安装（一次性）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点左上角「加载已解压的扩展程序」，选择本目录（`fadada-autofill`）
4. （推荐）在扩展列表里找到「法大大签约一键填充」→ 固定到工具栏

## 使用

1. 首次使用：打开一个已填过/待填的签署页 → 点插件图标 → 按组填好 13 项（或点「读取当前值」从页面抓取）→ 「授权书」组可点「同个人信息」一键复制 → **保存**
2. 以后每次：从墨语平台打开新的签署页，插件会**自动填充**（只填空框，不覆盖已有内容），也可以：
   - 点页面右下角悬浮按钮「⚡ 填充」
   - 或点插件图标 →「立即填充本页」（覆盖式填充所有已配置项）
3. 核对无误后手动点页面上的「确认提交」——**插件不会替你提交**

## 说明与注意事项

- 数据只存在本机 `chrome.storage.local`，不上传任何服务器
- 控件按「待处理控件」面板的顺序对应（该合同模板固定为上表顺序）；如果平台以后改模板导致顺序变化，填充结果请以页面实际显示为准
- 「打开签署页自动填充」和「悬浮按钮」都可以在弹窗里开关
- 更新插件代码后，需要在 `chrome://extensions` 里点一下插件的刷新图标，再刷新已打开的签署页

## 目录结构

```
fadada-autofill/
├── manifest.json   # MV3 清单
├── content.js      # 页面注入脚本：识别控件、写入值（Vue/Element 兼容）
├── popup.html      # 弹窗界面
├── popup.js        # 弹窗逻辑：编辑资料、读写 storage、发填充指令
└── icon128.png     # 图标（商店上架必需）
```

## 发布到 Chrome 应用商店（可选）

本插件满足上架的基本条件：MV3、单一用途、无远程代码、数据只存本机（不上传）。名称已按「仅服务蛙蛙平台作者」定位，描述中明示了适用范围。

发布步骤：

1. 注册开发者账号：https://chrome.google.com/webstore/devconsole ，一次性 $5 注册费（需能访问谷歌及外币支付）
2. 打包 zip 已备好：桌面上的 `fadada-autofill-store.zip`（manifest.json 在 zip 根目录）
3. 上传新商品 → 填名称/描述/分类（可用「生产力工具」）→ 上传 1280×800 截图 1~5 张
4. 隐私声明：填「不收集用户数据」（值仅存 chrome.storage.local）
5. 提交审核，新插件一般 1~7 天通过
